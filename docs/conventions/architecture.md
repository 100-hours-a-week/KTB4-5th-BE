# 아키텍처 컨벤션

## 확정 규칙

- 단일 Gradle 모듈로 개발한다.
- 업무 도메인 기준으로 패키지를 나누고 DDD 방식으로 모델링한다.
- 웹 계층은 Spring MVC, 기본 CRUD는 JPA를 사용한다.
- 다건 INSERT 성능 문제가 **측정되면** JdbcTemplate 배치를 검토한다.
- QueryDSL은 복잡한 조회·동적 검색이 필요할 때 검토하며 초기 의존성에 넣지 않는다.

## 미합의

도메인 내부 계층 이름, 참조 방향, 저장소 인터페이스 위치, 도메인 모델과 JPA Entity 통합 여부는 정하지 않았다. 기존 코드에 일관된 구조가 있으면 따르고, 첫 기능에서 필요해지면 합의 후 이 문서에 기록한다.
